# Prisca Oluebube — Personal Brand Website

A responsive personal-brand website introducing Prisca's digital marketing education and Newbie Affiliate Guide.

## Project files
- `index.html` — page structure and content
- `style.css` — responsive visual design
- `script.js` — navigation and interactions

## Add the media assets
Create an `assets` folder in the repository and upload these files using the exact filenames:
- `prisca-portrait.jpg` — Prisca's approved portrait (used in the circular hero frame)
- `testimonials.mp4` — approved testimonial video
- `testimonial-poster.jpg` — optional poster image for the video

The page references these local paths. Until the media files are uploaded, the portrait fallback and testimonial placeholder will remain visible.

## Before publishing
1. Confirm Prisca's biography and preferred contact details.
2. Confirm permission to publish the testimonial video and remove any private information from it.
3. Add the correct WhatsApp number and social profile links when supplied.
4. Check all content and media on mobile and desktop.

## Deployment
This is a static HTML/CSS/JavaScript project and is suitable for Cloudflare Pages. Use the repository root as the build output directory; no build command is required.
