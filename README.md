# Prisca Oluebube — Personal Brand Website

A responsive personal-brand website introducing Prisca Oluebube and the topics covered in her Newbie Affiliate Guide.

## Project files
- `index.html` — page structure and content
- `style.css` — responsive visual design
- `script.js` — mobile navigation and reveal interactions
- `prisca-portrait.jpg` — portrait used in the circular hero frame

## Current content notes
- The testimonial section is intentionally omitted for now.
- Prisca's direct contact link and social profile links can be added when she supplies them.
- Program pricing, delivery format and access details are intentionally not published because Prisca shares those directly.
- No earnings or outcomes are guaranteed.

## Deployment
This is a static HTML/CSS/JavaScript project and is suitable for Cloudflare Pages.

- Build command: leave blank
- Build output directory: `/` (repository root)
